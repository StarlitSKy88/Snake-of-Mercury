# 需求文档: 微信情感智能分析工具

## 目标
帮助用户分析指定微信好友的聊天记录，通过 AI 生成个性化沟通策略建议，按次付费。

## 核心功能 (MVP)
1. **数据获取**：用户通过电脑备份导出微信 SQLite 数据库，上传至网页
2. **好友选择**：用户选择想要分析的微信好友（系统读取数据库中的好友列表）
3. **行为分析**：聊天频率、时段分布、消息长度、表情使用、回复速度、主动发起比例
4. **话题画像**：高频词汇、兴趣领域推断
5. **AI 建议**：基于分析结果生成"这个人喜欢什么风格的对话"策略报告

## 产品形态
- Web 网页版（H5 适配，支持移动端浏览器）

## 数据安全
- 数据库文件临时处理，处理完毕自动删除
- 不做持久化存储
- 隐私声明透明

## 商业模式
- **直接付费**：分析一次 / 一个好友 = 一次付费
- 价格待定（建议 9.9-29.9 元区间）

## 技术架构建议
- 前端：网页（H5）
- 后端：服务器接收用户上传的 .db 文件
- 数据库解析：复用 OpenCLI 的解析逻辑（服务器端）
- AI 分析：接入大模型 API 生成策略建议

## 差异化
现有工具 = 聊天记录备份/检索
本产品 = 关系决策支持 + AI 沟通教练
