### 技术实现路径:

#### 推荐方案（Web 技术栈）
```
前端: HTML + CSS + JavaScript
├── 单文件即可完成
├── 可使用 Vue/React 简化状态管理
└── localStorage 实现数据持久化

或使用:
├── Flutter / React Native（移动端）
├── Electron（桌面端）
└── 小程序/快应用（国内平台）
```

#### 架构选择
```
极简版: 单页面 → 无后端 → localStorage 持久化
完整版: 前端 + 轻量后端 → 数据库存储
```
