### Sprint 划分建议

#### Sprint 1：核心功能 MVP（1-2 周）
```
✅ 最小可运行计数器
├── +1 / -1 按钮
├── 显示当前数值
├── 重置功能
└── 本地数据持久化
```

#### Sprint 2：体验增强（1 周）
```
├── 数值动画效果
├── 步长可配置（例：+5、+10）
├── 历史记录查看
└── 深色/浅色主题
```

#### Sprint 3：功能扩展（1 周）
```
├── 多计数器管理
├── 目标值设定与提醒
├── 数据导出功能
└── 基础 UI 优化
```

#### Sprint 4：稳定与发布（1 周）
```
├── 全平台测试
├── 性能优化
├── 文档编写
└── 发布上线
```
