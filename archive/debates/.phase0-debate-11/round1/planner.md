### Sprint 划分建议

#### Sprint 1: MVP - 核心功能
**目标：交付可用的基本计数器**

| 任务 | 描述 |
|------|------|
| UI 界面 | 显示当前计数值、+1/-1 按钮、重置按钮 |
| 计数逻辑 | 实现递增、递减、重置 |
| 交互反馈 | 按钮点击状态反馈 |
| 基础测试 | 核心功能测试覆盖 |

**交付物：** 一个可以在浏览器/手机上运行的简单计数器

#### Sprint 2: 增强功能（可选，视需求而定）
**目标：提升可用性与用户体验**

| 任务 | 描述 |
|------|------|
| 数据持久化 | 本地存储/云端同步 |
| 自定义步长 | 用户可设置每次增减的数值 |
| 历史记录 | 查看历史操作记录 |
